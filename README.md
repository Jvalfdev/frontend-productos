# Frontend Productos

Prueba técnica desarrollada en Angular para catálogo y compra de dispositivos móviles.

## Requisitos
* Node.js (v20 o superior)
* npm

## Instalación y ejecución

1. Instalar dependencias:
```bash
npm install
```

2. Arrancar en local:
```bash
npm start
```
Abrir en el navegador en `http://localhost:4200`

## Scripts

* `npm start`: Inicia el servidor de desarrollo en local.
* `npm run build`: Compila el proyecto para producción.
* `npm test`: Ejecuta los tests unitarios.
* `npm run lint`: Comprueba el formateo del código.
